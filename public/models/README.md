# S.19 3D Models Directory

Place your custom 3D model file here:
`/public/models/S19.glb` (or `/public/models/S19.gltf`)

The website's Three.js viewer will automatically detect, load, and render `S19.glb` with full interactive rotation, zoom, studio lighting, and floating physics.

When `S19.glb` is not present, the website automatically renders the precision procedural 3D S.19 model constructed according to the orthographic and beauty reference images.
